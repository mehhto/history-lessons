# Źródła prototypu wizualnego

Prototyp wykorzystuje lokalne kopie dwóch materiałów już zweryfikowanych w pakiecie `classes/4/jak-poznajemy-przeszlosc-historia-i-zrodla-historyczne/`. Kopie zachowują te same sumy SHA-256. Nie są nowymi ani zmodyfikowanymi źródłami.

## Kodeks Zamoyskich

- **Typ:** fotografia/scan rękopisu; źródło pisane, średniowieczny odpis kroniki.
- **Data obiektu:** XIV wiek; dokładna data nie jest podana w metadanych użytego pliku.
- **Lokalny plik:** `assets/codex-zamoyski.jpg`.
- **SHA-256:** `03efd1f71ce197e2adb27ee30391a141d92c85f3c05d34df8e5bacad18cd8d47`.
- **Strona:** https://commons.wikimedia.org/wiki/File:Codex_Zamoyscianus.jpg
- **Status:** domena publiczna.
- **Ograniczenie:** późniejszy odpis, nie autograf Galla Anonima; jedna karta nie przedstawia całej kroniki.
