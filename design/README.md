# Projektowanie jakości lekcji

Ten katalog przechowuje fundamenty dydaktyczne i wizualne rozwijane przed skalowaniem serii.

## Trwałe dokumenty

- [`quality-standard-v1.md`](quality-standard-v1.md) — bramki, rubryka oraz artefakty wymagane przed pełną budową lekcji.
- [`activity-library-v1.md`](activity-library-v1.md) — repertuar aktywności wybieranych według operacji myślowej, wieku i dowodu zrozumienia.

Oba dokumenty mają status v1 i wymagają pilotażu na lekcji wzorcowej oraz korekty po doświadczeniu klasowym.

## Prototypy do decyzji

- [`prototypes/visual-directions/`](prototypes/visual-directions/) — trzy kierunki wizualne pokazujące identyczne pięć funkcji slajdu.

Kod prototypu nie jest częścią produkcyjnego systemu motywów. Po decyzji należy zapisać wnioski, wchłonąć zatwierdzone zasady i usunąć prototyp.

## Zalecana kolejność

1. Porównać trzy kierunki wizualne z nauczycielem.
2. Zastosować standard i bibliotekę do storyboardu jednej lekcji wzorcowej.
3. Przeprowadzić lekcję i zapisać obserwacje w `reflection.md`.
4. Skorygować dokumenty v1.
5. Dopiero wtedy zmieniać generator, walidatory i motywy produkcyjne.
