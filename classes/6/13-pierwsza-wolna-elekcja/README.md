# Pierwsza wolna elekcja — korona za warunki

Klasa VI, do 15 uczniów (również do 20), 38 minut z buforem. Otwórz `index.html` przez istniejący prywatny panel. `S` — notatki, `F` — pełny ekran, strzałki — nawigacja, `B` — czarny ekran. Kliknij ilustrację, aby powiększyć; Escape zamyka.

- `worksheet.html`: jedna czarno-biała strona A4 na ucznia, do wklejenia; bez odpowiedzi.
- `teacher-guide.html`: prowadzenie krok po kroku, tekst i ilustracja każdego slajdu, notatki, klucz, pytania, wariant bez projektora i opcjonalne filmy.
- `student-summary.html`: pełna notatka dla nieobecnych/powtórki, nie drugi obowiązkowy wydruk.
- `sources.md`: źródła i prawa poza slajdami.

Pakiet do prywatnego przeglądu. Nie wykonano pushu. PDF/PPTX prezentacji dopiero po akceptacji i zamówieniu. Nie twierdzimy, że filmy w pełni odsłuchano, jeśli dokumentacja tego nie potwierdza.
