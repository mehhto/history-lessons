# Edytowalne prezentacje PowerPoint

Ten katalog zawiera eksporty PPTX trzech ostatnio przebudowanych lekcji:

- `starozytny-izrael.pptx` — klasa V;
- `renesans.pptx` — klasa VI;
- `front-wschodni-1941-1943.pptx` — klasa VIII.

Każdy plik ma osobne pola tekstowe, kształty i obrazy — nie jest zbiorem pełnoslajdowych zrzutów. Źródłem prawdy pozostają odpowiadające im prezentacje HTML w `classes/`; artefakty wymagają ponownego eksportu po zmianie ich `slides.md`, `lesson.css` lub lokalnych zasobów.
