# Lokalna kolekcja krojów prezentacyjnych

36 plików TrueType: po odmianie Regular (400) i Bold (700) dla 18 krojów. Pobrane z oficjalnego CSS API Google Fonts. Wszystkie mają sprawdzone polskie znaki: `ĄąĆćĘęŁłŃńÓóŚśŹźŻż`.

| Krój | Pliki | Zastosowanie |
| --- | --- | --- |
| Atkinson Hyperlegible | `atkinson-hyperlegible-{400,700}.ttf` | maksymalna czytelność, także dla trudniejszych warunków projekcji |
| DM Sans | `dm-sans-{400,700}.ttf` | neutralny tekst i zadania |
| Lexend | `lexend-{400,700}.ttf` | krótkie polecenia i slajdy dla młodszych klas |
| Manrope | `manrope-{400,700}.ttf` | współczesne, spokojne układy atlasowe |
| Nunito Sans | `nunito-sans-{400,700}.ttf` | żywsze lekcje klasy IV–VI |
| Source Sans 3 | `source-sans-3-{400,700}.ttf` | dłuższe objaśnienia i podpisy źródeł |
| Literata | `literata-{400,700}.ttf` | cytaty, dokumenty i narracja historyczna |
| Lora | `lora-{400,700}.ttf` | cytaty i krótsze nagłówki źródłowe |
| Merriweather | `merriweather-{400,700}.ttf` | wyraziste tytuły oraz istotne daty |
| Source Serif 4 | `source-serif-4-{400,700}.ttf` | tekst źródłowy i poważniejsze lekcje VII–VIII |
| IBM Plex Sans | `ibm-plex-sans-{400,700}.ttf` | techniczne wykresy, osie czasu i uporządkowane objaśnienia |
| Figtree | `figtree-{400,700}.ttf` | nowoczesne, lekkie układy i krótkie komunikaty |
| Work Sans | `work-sans-{400,700}.ttf` | zadania, porównania i gęstszy tekst projekcyjny |
| Instrument Sans | `instrument-sans-{400,700}.ttf` | wyraziste tytuły i spokojne slajdy klas VII–VIII |
| Alegreya | `alegreya-{400,700}.ttf` | żywsze nagłówki, cytaty i narracja klas IV–VI |
| Bitter | `bitter-{400,700}.ttf` | czytelne tytuły, liczby oraz dokumentowe cytaty |
| Cormorant Garamond | `cormorant-garamond-{400,700}.ttf` | krótkie eleganckie tytuły i podpisy dzieł; nie do długiego tekstu |
| Roboto Slab | `roboto-slab-{400,700}.ttf` | mapy, dane i poważne slajdy źródłowe |

Nie podłączaj wszystkich naraz do globalnego motywu. Wybieraj najwyżej parę: jeden sans do interfejsu/tekstu i jeden serif do tytułów lub źródeł.
