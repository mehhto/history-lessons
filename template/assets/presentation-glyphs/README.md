# Glyphy prezentacyjne

Ten katalog zawiera 17 neutralnych glyphów SVG z projektu [Lucide](https://lucide.dev/), pobranych z commitu [`951813ce76a859d4d8b145366972cbb237147a4e`](https://github.com/lucide-icons/lucide/tree/951813ce76a859d4d8b145366972cbb237147a4e). Licencja **ISC** znajduje się w pliku [`LICENSE`](LICENSE).

## Użycie

Glyph oznacza funkcję informacji; nie jest ozdobą pustego miejsca. Używaj najwyżej jednego małego glyphu przy nagłówku, etykiecie lub kluczowym kroku. Nie zastępuje źródła historycznego, mapy, fotografii ani słowa pisanego.

| Plik | Znaczenie |
|---|---|
| `book-open.svg` | pojęcie / wiedza |
| `calendar-days.svg` | data lub okres |
| `clock-3.svg` | czas pracy |
| `file-text.svg` | dokument |
| `landmark.svg` | instytucja / państwo |
| `map.svg` | przestrzeń / mapa |
| `milestone.svg` | punkt zwrotny |
| `quote.svg` | cytat źródłowy |
| `route.svg` | droga, migracja lub proces |
| `scale.svg` | porównanie / równowaga |
| `scroll-text.svg` | tekst dawny |
| `search.svg` | badanie źródła |
| `users.svg` | grupy społeczne |
| `pen-line.svg` | zapis ucznia |
| `list-tree.svg` | klasyfikacja |
| `lightbulb.svg` | wniosek |
| `arrow-right.svg` | kierunek przyczyny lub następstwa |

```html
<img src="../../template/assets/presentation-glyphs/map.svg"
     alt="" aria-hidden="true" data-no-lightbox class="slide-glyph">
```

Glyphy pozostają jednobarwne (`currentColor`). Kolor nadaj lokalnie przez `color`; nie wypełniaj ich wieloma kolorami ani nie używaj emoji jako zastępstwa.
