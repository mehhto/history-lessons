# Motyw prezentacji historii

Ten katalog jest wspólną, stabilną warstwą prezentacji. Treść nowej lekcji zapisuj w `classes/<klasa>/<temat>/`, a nie tutaj.

- `reveal/` — lokalna kopia silnika; odśwież ją przez `npm run sync:reveal`.
- `theme.css` — styl wspólny dla wszystkich prezentacji.
- `lesson/` — kompletna struktura kopiowana przez `npm run new`.
- `quality-checklist.md` — obowiązkowy audyt przed lekcją.
